操作说明

左键单击图新增一个样品点
1 / 2 / 3 / 4 …给选中的点设对应等级
点击已有点选中它（再按数字改判）
右键点 / Delete删除该点
Ctrl+Z撤销最后一个点
← → / 空格上一张 / 下一张
[ ]跳上一/下一张未判定图
P把当前图设为/取消「全景图（新组起点）」
Esc取消选中
左键拖动 / 滚轮平移 / 缩放（主图和悬浮全景图均可）

全景图按拍摄时间自动分组，可用 P 键手动改。判定实时保存到本地；「文件 ▾」菜单可导入图片、导出/恢复数据。导入的图片仅本次会话有效。
